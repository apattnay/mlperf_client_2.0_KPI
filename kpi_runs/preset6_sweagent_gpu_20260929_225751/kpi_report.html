Decode (●) re-reads the full weight per token (batch=1) - a small constant intensity (4.0 FLOPs/Byte) regardless of context length, the classic memory-bandwidth-bound signature. Points near/above a roof are running near that ceiling for this device. Memory roof (102.4 GB/s) is measured from this machine's actual memory configuration (channels × width × clock).
